# 📚 Assignment 1

### 📄 File: `assignment1.dart`

Assignment 1 contains five basic Dart programming problems focused on **conditions, loops, and mathematical operations**.

### 01️⃣ Positive, Negative or Zero

Check whether a given number is:

* 🟢 Positive
* 🔴 Negative
* ⚪ Zero

**Concept:** `if`, `else if`, `else`

---

### 02️⃣ Leap Year Checker 📅

Determine whether a given year is a leap year.

**Concept:** Conditional statements and logical operators.

---

### 03️⃣ Smallest of Three Numbers 🔢

Find the smallest number among three given numbers.

**Concept:** Comparison operators and conditional statements.

---

### 04️⃣ Multiplication Tables ✖️

Print multiplication tables from **1 to 10**.

**Concept:** Nested `for` loops.

---

### 05️⃣ Sum of Even Numbers ➕

Calculate the sum of all even numbers between **1 and 100**.

**Concept:** Loops, conditions, and arithmetic operations.

---

# 📚 Assignment 2

### 📄 File: `assignment2.dart`

Assignment 2 focuses on **number manipulation, mathematical logic, loops, and switch statements**.

### 01️⃣ Prime Numbers 🔢

Print all prime numbers between **1 and 100**.

**Concept:** Loops and prime-number logic.

---

### 02️⃣ Reverse the Digits 🔄

Reverse the digits of a given number.

**Example:**

```text
Input  : 12345
Output : 54321
```

**Concept:** Digit extraction and loops.

---

### 03️⃣ Palindrome Number 🔁

Check whether a number is a palindrome.

**Example:**

```text
121 → Palindrome ✅
123 → Not a Palindrome ❌
```

**Concept:** Number reversal and comparison.

---

### 04️⃣ Armstrong Number 🧮

Check whether a given number is an Armstrong number.

**Example:**

```text
153 = 1³ + 5³ + 3³
153 = 153

Therefore, 153 is an Armstrong Number ✅
```

**Concept:** Digit manipulation and mathematical operations.

---

### 05️⃣ Menu-Driven Calculator 🧮

Create a calculator using the **`switch` statement**.

```text
┌─────────────────────────┐
│     CALCULATOR MENU     │
├─────────────────────────┤
│  1. Addition            │
│  2. Subtraction         │
│  3. Multiplication      │
│  4. Division            │
│  5. Exit                │
└─────────────────────────┘
```

**Concept:** `switch`, user input, and arithmetic operators.
